## 问题描述

对一个整数数组进行排序，并去除重复元素，输出不重复的有序结果。

## 解题思路

1. 使用 `sort()` 对数组进行排序
2. 遍历排序后的数组，跳过与前一个元素相同的值
3. 只输出不重复的元素

## 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int arr[1005];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> arr[i];
    }

    // 排序：`less<int>()` 从小到大，`greater<int>()` 从大到小
    sort(arr + 1, arr + 1 + n, less<int>());

    // 输出第一个元素
    cout << arr[1] << endl;

    // 去重输出
    for (int i = 2; i <= n; i++) {
        if (arr[i] != arr[i - 1]) {
            cout << arr[i] << endl;
        }
    }

    return 0;
}
```

## 复杂度分析

| 操作 | 时间复杂度 |
|------|-----------|
| 排序 | `O(n log n)` |
| 去重遍历 | `O(n)` |

## 测试用例

**输入：**
```
5
3 1 2 3 2
```

**输出：**
```
1
2
3
```

## 注意事项

- `less<int>()` 表示升序排序，`greater<int>()` 表示降序排序
- 原代码在 `for` 循环前错误地使用了 `cout << arr[i] << endl;`，此时 `i` 的值为 `n + 1`，会导致越界访问，已修正为 `cout << arr[1] << endl;`
