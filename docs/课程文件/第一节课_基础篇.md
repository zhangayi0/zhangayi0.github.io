## 一、人工智能发展史

### 1.1 什么是人工智能？

**通俗定义**：让机器表现出类似人类智能行为的技术。

```
人类智能行为包括：
  看（视觉）→ AI 对应：计算机视觉
  听（听觉）→ AI 对应：语音识别
  说（语言）→ AI 对应：自然语言处理
  学（学习）→ AI 对应：机器学习
  想（推理）→ AI 对应：知识推理
```

### 1.2 AI 发展的三次浪潮

```
第一次浪潮（1950s～1970s）
  代表事件：1956 年达特茅斯会议，AI 正式被命名
  特点：符号主义，用"规则"教 AI 思考
  失败原因：计算能力有限，现实世界太复杂

第二次浪潮（1980s～1990s）
  代表事件：专家系统（医疗诊断 AI）兴起
  特点：把专家知识编码成规则，让 AI 据此判断
  失败原因：规则太多，维护成本极高

第三次浪潮（2010s～至今）
  代表事件：
    · 2012 年：AlexNet 深度学突破（图像识别）
    · 2016 年：AlphaGo 击败围棋世界冠军
    · 2022 年：ChatGPT 引发生成式 AI 热潮
  特点：大数据 + 强算力 + 深度学习
```

| 2016 | AlphaGo 击败李世石 | 强化学习震惊世界 |
| 2022 | ChatGPT 发布 | 人人都能用 AI 了 |

## 二、知识图谱——AI 怎样"记知识"？

### 2.1 从人脑记忆到知识图谱

**人脑记知识的方式**：建立联系

```
"苹果" 这个词，你会联想到：
  苹果 → 水果（类别关系）
  苹果 → 红色（颜色属性）
  苹果 → 牛顿（历史故事）
  苹果 → iphone（品牌）
```

AI 模仿这种方式，用**知识图谱**来存储知识。

### 2.2 知识图谱的基本结构

**三元组**：知识图谱的最小单位，格式是：

```
(主体，关系，客体)

示例：
  (姚明，效力于，休斯顿火箭)
  (休斯顿火箭，位于，休斯顿)
  (苹果，是一种，水果)
  (猫，喜欢吃，鱼)
```

用图形表示：

```
[姚明] ──效力于──▶ [休斯顿火箭] ──位于──▶ [休斯顿]
                                           │
                                       位于│
                                           ▼
                                        [德克萨斯州]
```

### 2.3 知识图谱 vs 普通数据库

| 对比项 | 普通数据库 | 知识图谱 |
|--------|-----------|---------|
| 存储方式 | 表格（行和列） | 图（节点 + 边） |
| 擅长的事 | 精确查询（"成绩大于 90 的学生"） | 关系推理（"姚明的球队在哪个州？"） |
| 新增知识 | 需要改表结构 | 直接加节点和边 |
| 典型案例 | 学校成绩管理系统 | 百度/谷歌的语义搜索 |

### 2.4 知识图谱的作用

1. **语义搜索**：搜索"苹果"，AI 知道你可能要找水果、手机品牌，还是童话故事？
2. **问答推理**：不经过人工编程，自动回答复杂问题
3. **推荐系统**：因为你看过《三体》，推荐刘慈欣的其他作品

## 三、机器学习的三种"学习方式"

### 3.1 三大范式总览

```
就像人类学习有不同方式，AI 学习也有三种主要方式：

方式一：有人教（监督学习）
  → 给 AI 大量"题目 + 正确答案"，让它学会做题

方式二：自己探索（无监督学习）
  → 只给 AI 大量数据，让它自己发现规律

方式三：试错学习（强化学习）
  → AI 通过"做对了给奖励、做错了给惩罚"来学习
```

### 3.2 监督学习（有人教）

**核心特点**：有标准答案（标注数据）

```
训练过程：
  输入：一张猫的图片 + 标签"猫"
  输入：一张狗的图片 + 标签"狗"
  ...
  AI 学习：猫和狗的区别特征
  测试：给它一张新图片，它能说出是猫还是狗
```

**典型任务：**

| 任务类型 | 输出是什么 | 例子 |
|---------|-----------|------|
| 分类 | 类别标签 | 邮件是"垃圾邮件"还是"正常邮件"？ |
| 回归 | 具体数值 | 这套房子值多少钱？ |

### 3.3 无监督学习（自己探索）

**核心特点**：没有标准答案，AI 自己找规律

```
例子：电商有 100 万用户数据
  → AI 自动把用户分成 5 类（高消费/偶尔购买/只浏览…）
  → 这个过程没有人事先告诉 AI "应该怎么分"
```

**典型任务**：用户分群、异常检测（发现异常交易）

### 3.4 强化学习（试错学习）

**核心特点**：通过奖励和惩罚学习

```
例子：教 AI 玩赛车游戏
  动作：向左转 → 冲出赛道 → 奖励：-10（惩罚）
  动作：保持在赛道 → 奖励：+1（小奖励）
  动作：第一个到达终点 → 奖励：+100（大奖励）
  
  经过上万次尝试，AI 学会了"怎样开最快又不出赛道"
```

**生活中的例子**：训练小狗坐下——坐下就给零食（奖励），不坐就没有（无奖励）

### 3.5 三种方式对比表

| | 监督学习 | 无监督学习 | 强化学习 |
|--|---------|------------|---------|
| 有没有"老师"？ | 有（标注数据） | 没有 | 有（奖励信号） |
| 数据要求 | 需要大量标注 | 不需要标注 | 需要能互动的环境 |
| 典型应用 | 图像分类、垃圾邮件过滤 | 用户分群、异常检测 | 游戏 AI、机器人控制 |
| 难度★ | ★★☆☆☆ | ★★★☆☆ | ★★★★☆ |

### 3.6 随堂练习

> **连线题**：把学习方式和对应的例子连起来
>
> ```
> 监督学习           AlphaGo 下围棋
> 无监督学习         用大量猫狗图片训练识别模型
> 强化学习           把班级同学按兴趣自动分组
> ```

## 四、AI 能帮我做什么？

### 4.1 身边的 AI 应用

```
打开手机，你已经在用 AI 了：
  · 刷短视频 → 推荐算法（无监督学习）
  · 拍照翻译 → 图像识别 + 机器翻译（深度学习）
  · 语音助手 → 语音识别 + 自然语言处理
  · 人脸解锁 → 计算机视觉（CNN）
  · 输入法联想 → 语言模型（预测下一个词）
```

### 4.2 AI 在各领域的大本事

**医疗**：
- 看 X 光片、CT 影像，辅助医生发现病灶
- 预测蛋白质结构（AlphaFold，帮助研发新药）

**交通**：
- 自动驾驶（特斯拉、百度 Apollo）
- 智能红绿灯（根据车流量自动调节）

**教育**：
- 个性化学习（哪个知识点没掌握，就多推相关题目）
- 作文智能批改（语法检查、给出修改建议）

**工业**：
- 工厂里用 AI 检查产品是否有瑕疵
- 预测机器什么时候会坏，提前维修

### 4.3 AI 目前还做不好的事

```
AI 的五点"短板"：
  ① 常识推理：你问"能把大象放进冰箱吗？"，AI 可能一本正经地给出步骤
  ② 情感理解：AI 能模拟安慰的语气，但它并不真正"心疼"你
  ③ 创造性：AI 的"创新"本质上是已有数据的重新组合
  ④ 长期规划：在复杂环境中做多步决策，AI 还不够可靠
  ⑤ 解释不清：深度学习是"黑盒"，它很难说清楚"为什么"做出这个判断
```

> **思考题**：上面 5 点短板中，你认为哪一点是最需要人类和 AI 协作的？为什么？

## 五、使用 AI 的伦理与安全须知

### 5.1 AI 伦理四大原则

```
① 公平性（Fairness）
   → AI 不能因为性别、种族、年龄而区别对待
   → 真实案例：某 AI 招聘系统学会了"歧视女性"（因为它学过的历史数据里男性更多）

② 透明性（Transparency）
   → AI 做出判断的依据，应该能解释清楚
   → 如果 AI 拒绝了你的贷款申请，银行应该告诉你"为什么"

③ 隐私保护（Privacy）
   → 个人数据不能被 AI 随意收集和使用
   → 你的人脸、指纹、行踪都是敏感信息

④ 问责制（Accountability）
   → 如果 AI 犯了错，应该有人（或机构）负责
   → 自动驾驶出了事故，责任如何认定？
```

### 5.2 青少年使用 AI 的安全准则

```
✅ 做的事：
  · 对 AI 生成的内容保持疑问（它可能"幻觉"——自信地说错话）
  · 使用学校或家长认可的 AI 工具
  · 遇到不舒服的内容，立即停止并告知家长/老师

❌ 不能做的事：
  · 向 AI 透露姓名、学校、家庭住址等个人信息
  · 上传包含个人信息的照片
  · 用 AI 代替自己的思考（依赖 AI 完成作业）
```

### 5.3 什么是"AI 幻觉"？

**定义**：AI 自信地输出错误（甚至荒谬）内容，而它"自己不知道"自己错了。

```
例子：
  问：中国第一位获得诺贝尔奖的科学家是谁？
  AI 可能回答：屠呦呦（正确）✓
  也可能回答：李白（荒谬）✗ ——但它说得很自信！

应对方法：
  ① 重要信息一定要用可靠来源交叉验证
  ② 问 AI "你确定吗？请列出信息来源"
  ③ 涉及健康、法律、学业的重要决策，不要盲目相信 AI
```
