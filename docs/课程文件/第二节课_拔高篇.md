## 一、深度学习——神经网络怎样"学习"？

### 1.1 神经网络的结构

**灵感来源**：模仿人脑神经元

```
人脑神经元：               神经网络：
  树突（接收信号）   →  输入层（接收特征）
  细胞体（处理信号） →  隐藏层（提取规律）
  轴突（传出信号）   →  输出层（给出预测）

多个神经元连接 → 多层 → 深度神经网络
```

**神经网络工作示意图：**

```
输入层（特征）      隐藏层（自动学习特征）      输出层（预测结果）
  ●  ──→  ●  ●  ●  ──→  ●  （分类：猫/狗/鸟）
  ●  ──→  ●  ●  ●  ──→  ●  （回归：预测房价）
  ●  ──→  ●  ●  ●
```

- **权重**（连接线上的数值）：决定信息传递的强弱，训练就是调整这些权重
- **激活函数**：引入"非线性"，让神经网络能学习复杂规律（没有它，多层网络等价于一层）
- **反向传播**：根据预测误差，从输出层反向调整各层权重

### 1.2 三种核心网络架构

**① CNN（卷积神经网络）—— 图像的"眼睛"**

```
图片像素输入
      ↓
[卷积层] 用"滤镜"扫描图片，提取边缘、纹理、形状
      ↓
[池化层] 压缩图片尺寸，保留关键特征（像把图片"缩小"）
      ↓
[全连接层] 综合所有特征，给出分类结果（猫/狗/…）
```

**适用**：图像识别、人脸检测、医学影像分析

**② RNN/LSTM（循环神经网络）—— 语言的"记忆"**

```
处理句子"我爱篮球"：
  "我" → 编码 → 记住"我"
         ↓
  "爱" → 编码 → 结合"我"+ "爱"
         ↓
  "篮球" → 编码 → 结合上文理解"我爱篮球"
```

**问题**：句子太长时，早期信息会"遗忘"（梯度消失）

**③ Transformer —— 大模型的基石**

CNN 和 RNN 的局限：

```
CNN：擅长图像，但处理语言时无法理解"上下文语境"
RNN：能理解语境，但必须一个词一个词处理（慢），且长句子会遗忘
```

**Transformer 的革命性突破：**

- **自注意力机制**：每个词同时"看"句子中所有其他词，直接捕捉长距离关系
- **并行计算**：不再需要一个词一个词处理，训练速度提升数十倍
- **多头注意力**：同时关注语法、语义、指代等多种关系

### 1.3 生成式 AI 工作原理

**大语言模型（LLM）是怎样"写文章"的？**

```
Step 1：把你的提示词切成"词块"（Tokenization）
  "写一首关于春天的诗"
  → [写][一首][关于][春天][的][诗]

Step 2：每个词块转换成向量（数字表示），送入 Transformer

Step 3：模型预测"下一个最可能的词"
  → 预测下一个词是"春"，放入输出
  → 再以"春"为输入，预测再下一个词
  → 循环，直到生成完整诗句

这就是"逐词生成"的原理。
```

**主流生成式 AI 工具对比：**

| 类型 | 代表工具 | 你能用它做什么 |
|------|---------|--------------|
| 文字生成 | ChatGPT、文心一言、讯飞星火 | 写作文、解数学题、翻译、编程 |
| 图像生成 | Midjourney、Stable Diffusion | 画插画、设计海报、生成概念图 |
| 视频生成 | Sora、Runway | 把文字描述变成短视频 |
| 音频生成 | Suno、天工 AI | 生成背景音乐、朗诵音频 |

### 1.4 提示词工程（让 AI 更好用）

**四个要素，写出高质量提示词：**

```
┌─────────────────────────────────────────┐
│  ① 角色设定   "你是一位经验丰富的物理老师"  │
│  ② 任务描述   "帮我解释什么是牛顿第三定律"    │
│  ③ 约束条件   "用初中生能懂的语言，不超过200字" │
│  ④ 输出格式   "先解释原理，再举一个生活例子"   │
└─────────────────────────────────────────┘
```

**对比实验：**

| | 简单提示词 | 优化提示词 | 效果差异 |
|--|-----------|-----------|---------|
| 写作文 | "写一篇关于环保的文章" | "以初中生视角，用第一人称，写一篇 600 字关于校园节能的议论文，包含具体数据和案例" | 优化后文章结构更清晰、内容更具体 |
| 解数学题 | "解这道方程组" | "请逐步讲解这道二元一次方程组的解法，每一步说明用了什么方法，用初中生能理解的语言" | 优化后能看到思维过程，真正学会方法 |

> **动手任务**：选一个你正在学习的学科知识点，用"四要素法"写一个提示词，让 AI 帮你讲解，对比效果差异。

### 1.5 AI 幻觉与输出质量评估

**什么是"AI 幻觉"（Hallucination）？**

> AI 有时会非常自信地输出错误（甚至荒谬）的内容，这叫做"幻觉"。
> 例如："中国第一位获诺贝尔奖的科学家是李白"（荒谬，但 AI 可能一本正经地输出）

**鉴别 AI 输出质量的 5 个问题：**

1. 这个结论能在教科书或权威网站（如百度百科、政府官网）上查到吗？
2. AI 的推理过程有没有逻辑漏洞？（比如偷换概念、因果倒置）
3. 内容是否带有明显的偏见？（性别/地域/种族歧视等）
4. 数据和事实是不是已经过时了？
5. 有没有更好的答案或角度，被 AI 遗漏了？

## 二、强化学习——AI 怎样通过"试错"变强？

### 2.1 强化学习五要素

**核心思想**：像训练宠物一样——做对了给奖励，做错了不给（或给惩罚），AI 通过大量尝试学会最优策略。

```
┌──────────────────────────────────────────────┐
│              强化学习框架                       │
│                                              │
│   环境 (Environment)                          │
│     │                                        │
│     │ 状态 s (State)                          │
│     ↓                                        │
│   智能体 (Agent) ──动作 a(Action)──→ 环境      │
│     ↑                                        │
│     │ 奖励 r (Reward) + 新状态 s'              │
│     └──────────────────────────────          │
└──────────────────────────────────────────────┘
```

| 要素 | 含义 | 游戏 AI 示例 |
|------|------|-------------|
| **智能体**（Agent） | 做决策的主体 | 游戏中的角色 |
| **环境**（Environment） | AI 所处的世界 | 游戏地图 |
| **状态**（State） | 当前情况的完整描述 | 角色位置、血量、敌人位置 |
| **动作**（Action） | 可以采取的操作 | 上/下/左/右/攻击/防御 |
| **奖励**（Reward） | 动作好坏的反馈信号 | 吃金币 +10，掉坑 -100，胜利 +1000 |

---

### 2.2 Q 值——动作好坏的"评分"

**Q 值（动作价值）**：在状态 s 下执行动作 a，如果之后都按最优策略行动，能获得多少累积奖励。

**直观理解**：

```
想象你是一个游戏 AI，"Q 值"就是你对每个动作的"信心分"：

状态：角色在位置 A
  动作"向右"：Q = 8.5  ← 以前试过，向右通常有高奖励
  动作"向左"：Q = 2.1  ← 向左经常碰壁，不太好
  动作"向上"：Q = 6.0
  
智能体会选 Q 值最高的动作（"利用"），
但有时也会随机选一个低 Q 值的动作（"探索"），也许能发现更好的策略。
```

---

### 2.3 探索 vs 利用——强化学习的核心平衡

```
探索（Exploration）：
  → 尝试没做过的动作，可能发现更好的策略
  → 相当于"冒险尝试新路线"

利用（Exploitation）：
  → 使用已知最好的动作，稳定获取奖励
  → 相当于"走已经知道的最快路线"

只探索：永远在乱试，学不到稳定策略
只利用：永远用当前最好的，可能错过更优策略
```

**好的强化学习算法**：训练初期多探索（ε 大），训练后期多利用（ε 小）。

---

### 2.4 强化学习经典案例：AlphaGo

```
AlphaGo 学围棋的三阶段：

阶段一：监督学习
  → 学习了 3000 万局人类高手棋谱
  → 先达到人类业余高手水平

阶段二：强化学习（自我对弈）
  → AI 左手机器人和右手机器人对下
  → 赢了的策略获得奖励，输了的策略获得惩罚
  → 经过数百万局自我对弈，超越人类顶尖水平

阶段三：蒙特卡洛树搜索（比赛实战）
  → 结合前面学到的策略，实时计算最优落子
  → 最终 4:1 击败李世石
```

> **思考题**：为什么 AlphaGo 不直接用人类棋谱，还要自我对弈？（提示：人类棋谱里没有"AI 发现的新棋路"）

### 2.5 Q 值计算实战

> **计算题**：一个小迷宫机器人，参数设置：γ（折扣因子）= 0.9，到达目标的奖励 = +100，每走一步的代价 = -1。
>
> 已知：
> - 从状态 S2 执行"向下"可以直接到达目标，奖励 r = -1，下一状态最大 Q 值 = 100×0.9 = 90
> - Q(S2, 向下) 的旧值 = 0（还不知道这个动作好）
>
> **请计算**：
> 1. 目标值 = r + γ × max Q(s', a') = ？
> 2. 若学习率 α = 0.5，更新后的 Q(S2, 向下) = ？
>
> ---
> **参考答案**：
> 1. 目标值 = (-1) + 0.9 × 90 = -1 + 81 = **80**
> 2. 新 Q 值 = 旧值 + α × (目标值 - 旧值) = 0 + 0.5 × (80 - 0) = **40**
> （经过多次更新，Q 值会逐渐接近真实价值 80）

## 三、具身智能——有身体的 AI

### 3.1 离身智能 vs 具身智能

| 对比项 | 离身智能（Disembodied） | 具身智能（Embodied） |
|--------|------------------------|----------------------|
| **定义** | 没有物理载体的软件 AI | 拥有实体身体，能在物理世界中行动 |
| **如何与环境交互** | 通过数字接口（键盘输入、屏幕输出） | 直接通过传感器感知、执行器行动 |
| **典型代表** | ChatGPT、翻译软件、推荐算法 | 波士顿动力机器人、自动驾驶汽车、无人机 |
| **主要挑战** | 缺乏常识、容易产生幻觉 | 实时控制、多传感器融合、物理世界的不确定性 |
| **你用过吗？** | 每天都在用（聊天 AI、推荐视频） | 较少直接接触，但在工厂/仓库中已大量应用 |

---

### 3.2 具身智能的"感知—决策—行动"回路

```
         ┌── 环境（物理世界）──┐
         │                      │
    [传感器感知]         [执行器行动]
         │                      │
    摄像头（看见）         机械臂（抓取）
    麦克风（听见）         轮子/腿（移动）
    力觉传感器（摸到）     扬声器（发出声音）
         │                      │
         └──→ [AI 决策] ←────┘
                  │
          分析感知信息，决定"下一步做什么"
```

**真实案例拆解：自动驾驶汽车**

```
感知层：摄像头（看路标）、雷达（测距）、GPS（定位）
         ↓
决策层：AI 分析 → 现在要左转，但对面有车来，需要等
         ↓
执行层：控制方向盘（左转）、控制油门和刹车（加速/减速）
         ↓
反馈：摄像头发现前方红灯 → 重新决策 → 刹车
```

### 3.3 Sim-to-Real（从仿真到现实）

**为什么不直接在真实机器人上训练？**

```
真实机器人训练的问题：
  ① 慢：现实世界的时间是"实时"的，学一个走路动作可能要摔几千次
  ② 贵：机器人摔坏一次，维修成本很高
  ③ 危险：某些场景（如救灾机器人）直接在真实环境训练太危险
```

**解决方案：先在仿真环境中大量训练，再迁移到真实机器人**

```
步骤一：在计算机里建立一个"虚拟机器人"和"虚拟环境"
         （物理规律尽量和真实世界一致）

步骤二：让虚拟机器人在虚拟环境里通过强化学习大量试错
         （可以 1000 倍速训练，摔几万次也没成本）

步骤三：把训练好的"策略"迁移到真实机器人
         （这就是 Sim-to-Real 迁移）

挑战：虚拟环境和真实世界总有差距（光照、摩擦、传感器噪声）
      → 需要用"领域随机化"等方法缩小这个差距
```

### 3.4 具身智能方案设计挑战

> **设计题**：你要为"校园图书馆图书整理机器人"设计方案，请完成：
>
> **① 传感器选择**：机器人需要哪些传感器？为什么？
>
> | 传感器 | 用途 | 必要性 |
> |--------|------|--------|
> | 摄像头 | 识别书名和书架号 | ★★★★★ 必需 |
> | 力觉传感器 | 感知抓书的力度，避免损坏 | ★★★★☆ 重要 |
> | 激光雷达 | 检测前方是否有人/障碍物 | ★★★★☆ 重要 |
> | 麦克风 | 接收语音指令（如"请把这本书放到二楼"） | ★★★☆☆ 加分项 |
>
> **② 算法选择**：不同子任务适合不同的 AI 算法，请分析：
>
> | 子任务 | 推荐算法 | 理由 |
> |-------|---------|------|
> | 识别书脊上的文字 | 监督学习（CNN + OCR） | 有大量标注好的书名数据可用 |
> | 决定抓取力度 | 强化学习 | 需要通过试错学习"恰到好处"的力度 |
> | 规划从 A 区到 B 区的路径 | 传统算法（A* 寻路） | 这是确定性问题，不需要 AI 学习 |
>
> **③ 奖励函数设计**（如果你是强化学习训练抓取动作）：
> - 成功抓起书本：+10
> - 书本滑落损坏：-20（惩罚要大于奖励，防止"不在乎损坏"）
> - 每耗时 1 秒：-0.1（鼓励快速完成）
>
> **④ 潜在失败场景预测**：
> 1. 光线太暗，摄像头识别失败 → 解决：加装补光灯
> 2. 书本堆叠太紧，抓取失败 → 解决：先推松再抓取
> 3. 突然有人走过，来不及避让 → 解决：力觉传感器检测到阻力立即停止
> 4. 相似书名混淆（如《数学》和《数学练习册》）→ 解决：OCR 后人工二次确认

## 四、系统思维与批判性评估

### 4.1 系统思维——用"整体眼光"看 AI

**系统三要素：**

```
要素（Elements）：系统的各个组成部分
  → AI 系统的要素：数据、算法、算力、用户、监管方…

连接（Connections）：要素之间如何互相影响
  → 数据质量影响模型效果，模型效果影响用户体验，用户体验影响数据收集…

功能/目标（Purpose）：系统的整体目标是什么？
  → 一个"AI 批改作文系统"的目标是"减轻教师负担，同时保证评分公平"
  → 如果只优化"减轻负担"（批改速度），可能牺牲公平性（评分不准）
```

**用系统思维分析"AI 推荐系统"：**

```
要素：用户、视频内容、推荐算法、广告商
连接：
  用户观看 → 算法学习偏好 → 推荐更多类似内容
  → 用户越看越"沉浸" → 广告商获益 → 平台推荐更多"让人上瘾"的内容
  → 用户视野越来越窄（信息茧房）

目标反思：推荐系统的设计目标是"用户利益最大化"还是"平台利益最大化"？
          这可能是伦理冲突的根源。
```

### 4.2 SWOT + E 评估框架

**评估任何 AI 方案的五维框架：**

| 维度 | 英文 | 核心问题 | 应用示例（AI 批改作文） |
|------|------|---------|----------------------|
| **优势** | Strengths | 这个方案的核心优点？ | 批改速度快，不知疲倦，标准统一 |
| **劣势** | Weaknesses | 技术上有什么局限？ | 无法真正理解文章情感和创意，只能按套路评分 |
| **机会** | Opportunities | 未来可以怎样改进？ | 结合大模型，提升对创意和情感的识别能力 |
| **威胁** | Threats | 可能带来什么风险？ | 学生过度依赖，不再锻炼自己的写作能力 |
| **伦理** | Ethics | 有没有伦理问题？ | 评分过程不透明（黑盒），学生不知道为什么被扣了分 |

> **实战练习**：用 SWOT + E 框架评估"AI 人脸识别校园门禁系统"，每个维度写 1-2 条。

### 4.3 算法横向对比——遇到 AI 问题，选哪个算法？

```
面对一个 AI 问题，选择算法的决策树：

第 1 问：有没有大量标注好的数据？
  → 有 → 监督学习（CNN 图像/ Transformer 文本）
  → 没有 → 继续第 2 问

第 2 问：是不是"一系列连续决策"的问题（当前决策影响未来）？
  → 是 → 强化学习（DQN / PPO）
  → 不是 → 继续第 3 问

第 3 问：需要理解"实体之间的关系"吗？
  → 是 → 知识图谱 + 图神经网络
  → 不是 → 继续第 4 问

第 4 问：数据量极少，需要知道"不确定度"吗？
  → 是 → 贝叶斯方法
  → 不是 → 尝试无监督学习（聚类/降维）
```

**三大主流强化学习算法对比：**

| | Q-Learning | DQN | PPO |
|--|------------|-----|-----|
| 动作空间 | 离散（有限个） | 离散 | 离散 **或** 连续 |
| 用神经网络吗？ | 不用（用 Q 表） | 用（深度 Q 网络） | 用（Actor-Critic 结构） |
| 适合场景 | 状态空间很小的问题 | Atari 游戏 | 机器人控制（连续动作） |
| 稳定性 | 高（小问题） | 中等 | 高 |

## 五、AI 伦理深度与科技自主

### 5.1 复杂伦理场景分析

**场景一：自动驾驶的"电车难题"**

```
不可避免要发生碰撞时，AI 应该优先保护：
  A. 车内乘客（包括你）
  B. 车外更多的行人
  
功利主义视角：选 B（保护更多人）
义务论视角：不应主动伤害乘客（选 A 或不主动转向）
```

**这不只是哲学讨论**——法律需要明确规定，AI 系统的"价值观"必须由人类社会共同决定，不能由程序员私自设定。

---

**场景二：AI 监控与隐私的平衡**

```
某城市计划在全市部署 AI 人脸识别：
  支持方：犯罪率预计下降 40%，失踪人口找回率大幅提升
  反对方：每个市民的行踪都被记录，隐私权受到严重侵犯

两难：安全 vs 自由，如何平衡？
```

**可能的折中方案**：

- 数据匿名化处理（识别"有异常行为"但不记录"某人在某时出现在某地"）
- 设置数据保存期限（如 30 天后自动删除）
- 建立独立监督机构，防止监控系统被滥用

---

### 5.2 AI 生成内容的版权问题

**三个前沿法律问题（目前法律尚未完全明确）：**

```
问题 ①：AI 用百万张有版权的图片训练，输出新图片——侵权吗？
  → 各国法律正在讨论中，尚未有统一结论

问题 ②：AI 辅助创作的作品，版权归谁？
  → 候选答案：AI 公司 / 使用者 / 无人拥有（公共领域）
  → 中国目前倾向：AI 生成内容不受版权保护，但"人类创造性参与"的部分受保护

问题 ③：AI 生成的新闻/文章如果包含错误，谁来负责？
  → 发布媒体？AI 开发商？还是使用 AI 的人？
  → 目前趋势：使用 AI 的人负有最终审核责任
```

---

### 5.3 科技自主可控

**为什么"科技自主可控"很重要？**

```
AI 技术栈的四层：

应用层（各类 AI 产品）
  ↑ 中国较强（文心一言、通义千问、讯飞星火…）
框架层（PyTorch / 飞桨 / MindSpore）
  ↑ 中国有明显进展（飞桨在国内市场份额已超 PyTorch）
芯片层（训练 AI 用的 GPU / NPU）
  ↑ 中国仍依赖进口（受国际制裁影响，高端 GPU 很难买）
```

**"卡脖子"风险**：如果高端 AI 芯片被断供，中国的大模型训练能力将受到严重影响。

**中国 AI 的相对优势：**

- 应用场景丰富（14 亿人口，海量数据）
- 政府对 AI 发展的大力支持
- 中文 AI 和中文数据方面有天然优势
- 制造业 AI 应用深入（工厂智能化走在世界前列）
